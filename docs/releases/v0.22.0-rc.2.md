# Noema v0.22.0-rc.2

Second release candidate for v0.22.0. This prerelease includes the storage and MCP improvements from RC1 plus embedding reliability and service startup fixes. The stable release and Homebrew remain on v0.21.9 pending qualification.

## Changes since RC1

- Recover from recognized embedding context and batch-size limits by isolating oversized inputs and preserving successful neighboring embeddings.
- Support optional exact token budgets through a compatible tokenizer on the embedding server. Trimming affects derived embedding input only; stored traces remain intact.
- Track truncated vectors, preparation metadata, and retry cooldowns. Apply cooldown before backfill limits so an oversized trace does not block later work; report incomplete coverage clearly.
- Rebuild stale embeddings when preparation settings or trace titles change. Migration 022 preserves existing vectors while adding local derived-index metadata.
- Wait up to 30 seconds for configured static listener addresses to become available during startup. Keep ready listeners bound and fail port conflicts and permission errors immediately.

## Compatibility and qualification

Existing vectors become stale for backfill when they lack preparation metadata. Token budgets are opt-in; providers without compatible tokenization cannot perform automatic size recovery. Trace contents and federation format are unchanged.

This is a prerelease for runtime qualification before the planned October 3 stable release. Stable promotion depends on successful cross-platform builds, artifact verification, and a clean soak of the published candidate.
