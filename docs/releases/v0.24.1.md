# Noema v0.24.1

This patch adds a portable installer and static Linux builds for broader
distribution compatibility. Existing glibc archives and Homebrew installation
are unchanged.

## Portable installer

Install on Linux or macOS without sudo:

```sh
curl -fsSL https://noemacortex.com/install.sh | sh
```

The POSIX sh installer selects the matching amd64 or arm64 archive, verifies its
SHA-256 checksum against `checksums.txt`, and installs to `~/.local/bin`. It prints
PATH instructions when needed without editing shell startup files.

- Set `NOEMA_VERSION` to pin a stable or prerelease version.
- Set `NOEMA_INSTALL_DIR` to override the destination directory.
- Set `NOEMA_SKIP_VERIFY=1` to permit installation when neither `sha256sum` nor
  `shasum` is available. Available verification tools still verify the archive
  and reject checksum mismatches.

The release includes `install.sh` as a downloadable asset. Stable releases
notify the website to redeploy when the release-dispatch credential is configured;
prereleases do not trigger that notification.

## Static Linux builds

Linux releases add `noema_<ver>_linux_amd64_musl.tar.gz` and
`noema_<ver>_linux_arm64_musl.tar.gz`. These static archives avoid a system glibc
requirement and support older glibc distributions and Alpine.

The installer prefers musl archives on Linux. For older releases without one,
it falls back to the glibc archive and warns about potentially incompatible
systems. On macOS it selects the native archive and ad-hoc signs the executable
when `codesign` is available.

## Upgrade

```sh
brew update
brew upgrade noema
```

Alternatively, use the installer above, download the matching platform archive
and verify it against `checksums.txt`, or build from the v0.24.1 source tag.
Restart Noema servers and stdio MCP clients after upgrading to use the new
executable. The installer does not reconcile launchd services.

No Cortex data or configuration migration is required. No unrelated integration,
tag-review, plugin, or dependency updates are included.

## Verification scope

Release-candidate compatibility checks verified the static Linux builds on
Debian 12, Ubuntu 22.04, Alpine 3.20, and Rocky 9. These checks cover the release
candidate; they are not a claim that every Linux distribution has been tested.
Release builds also check that musl executables have no dynamic interpreter or
shared-library dependencies.
