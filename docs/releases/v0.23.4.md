# Noema v0.23.4

This patch adds agent-readable onboarding guides bundled with the Noema binary.

## Agent-guided setup

```sh
noema instructions
noema instructions quick-start
noema instructions federation
```

Ask your AI agent to run `noema instructions quick-start` and help you follow it.
The guide covers shell completion installation and activation, creating or
selecting a Cortex, connecting an agent through MCP, and verifying an actual
memory create/get/search round-trip through that agent.

The optional federation guide covers peer identities, sharing direction,
authentication, TLS, event signing, persistent services, and verification on
real peers. It distinguishes remote access to one Cortex from replication
between distinct Cortexes.

These commands only print instructions. They do not install packages, change
configuration, create Cortexes, start services, or contact peers. They work
without a configured Cortex and remain available even when local Noema
configuration cannot be parsed. The guides travel with the binary and can be
printed offline without a source checkout.

Existing integration and federation behavior is unchanged. This release does
not include unrelated integration, tag-review, or dependency changes.

## Upgrade

```sh
brew update
brew upgrade noema
```

Alternatively, download the matching platform archive from this release and
verify it against `checksums.txt`, or build from the v0.23.4 source tag.
No Cortex data or configuration migration is required.
