# Noema v0.23.1

This patch renames the decision-assisted retrieval operator surface from vendor
branding to capability naming.

## Changes

- CLI is now `noema decision status|metrics|probe|gate|pair`.
- Config key is now `decision:`.
- Hosted default credential env remains `TYPESAFE_API_KEY` and is still
  overridable with `token_env:`.
- `typesafe` / `typesafe_ai` names are removed with no compatibility aliases.
- Docs refer to TypeSafe and Clef only as provider identifiers.

## Upgrade

```sh
brew update
brew upgrade noema
```

Update local config from:

```yaml
typesafe_ai:
  enabled: auto
```

to:

```yaml
decision:
  enabled: auto
```

Then restart Noema servers and stdio MCP clients. Existing Cortex data remains
compatible. Retrieval metrics continue under `decision_retrieval`.
