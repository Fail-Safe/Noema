# Noema v0.23.5

This patch improves question-scoped lexical prefetch and publishes a separate,
reviewed continuity experiment. It does not change the September qualification.

## Prefetch

- Retrieve evidence for independent questions before merging their results, so
  unrelated instructions and a busy first question do not crowd out later ones.
- Preserve requested identifiers, scope, version, and status constraints; reject
  contradictory or absent evidence rather than filling the context with nearby
  topics.
- Deduplicate overlapping results and retain global candidate, result, and
  character bounds. Existing optional decision evaluation remains separate.

## Evaluation and evidence

The descriptive harness now compares hierarchical native instructions,
equal-access shared Markdown, and Noema prefetch. It separates reachability from
retrieval/evidence quality and reports boundary, update, and scoping subsets.
Independent synthetic corpora and guarded collection support larger validation.

The [November evidence bundle](../../tests/omarchy-eval/published/continuity-2026-11/README.md)
retains unfavorable and aborted stages alongside the frozen-profile validation.
It includes reviewed numerical projections, provenance, checksums, and portable
analysis/profile tooling. Raw prompts, responses, Cortex contents, reconstructive
seeds, and local configurations remain private. Statistical reanalysis is
reproducible; private response-level grading is not independently verifiable.

These are descriptive results for the tested synthetic generator and fixed
models, not a formal superiority or equivalence claim. The September tables are
unchanged. No new live model campaign is required to install this patch.

The portable 8k profile is opt-in experimental tooling, not a change to the
default benchmark delivery budgets. Historical source fingerprints remain
records of the study snapshots, not hashes of this version-bumped release tree.

## Upgrade

```sh
brew update
brew upgrade noema
```

Alternatively, download the matching platform archive and verify it against
`checksums.txt`, or build from the v0.23.5 source tag. Restart Noema servers and
stdio MCP clients after upgrading to use the new executable.

No Cortex data or configuration migration is required. No unrelated integration,
tag-review, plugin, or dependency updates are included.
